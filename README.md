# Goat Life — Releases

This repo holds nothing but public release artifacts for **Goat Life**, a
little goat that lives on your macOS desktop.

- Built app versions are published here as GitHub Releases.
- `appcast.xml` is the [Sparkle](https://sparkle-project.org) update feed the
  app polls, regenerated by CI on every release.

Source code is private. This repo exists only so Sparkle can check for and
download updates without needing anyone to authenticate.
